
# ScarletMarketing

## Descrição

**ScarletMarketing** é uma aplicação desenvolvida para fornecer soluções de marketing digital. O projeto visa otimizar a presença digital de empresas por meio de diversas ferramentas e estratégias, integrando análises de dados, SEO, e automação para aumentar a visibilidade online e gerar melhores resultados.

## Funcionalidades

- **Análises de SEO**: Ferramentas para avaliar o desempenho de sites em mecanismos de busca.
- **Automação de Marketing**: Soluções para otimizar campanhas e interações com clientes.
- **Relatórios e Estatísticas**: Geração de relatórios detalhados para monitoramento de desempenho.
- **Integrações**: Conecta com diversas plataformas e redes sociais para um marketing digital completo.

## Tecnologias Utilizadas

- **JavaScript (Node.js)**: Linguagem para o backend e automação.
- **React**: Framework para o desenvolvimento da interface do usuário.
- **Nunjucks**: Para templates dinâmicos no front-end.
- **11ty**: Gerador de site estático para a parte de conteúdo.
- **Vercel**: Hospedagem e deploy contínuo da aplicação.
- **Minify**: Ferramenta para compactação e otimização de arquivos.

## Como Rodar o Projeto

Primeiro, faça o clone do repositório:

```bash
git clone https://github.com/Nugguet/scarletMarketing.git
cd scarletMarketing
```

Instale as dependências necessárias:

```bash
npm install
```

Após instalar as dependências, você pode rodar o projeto localmente:

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5174`.

Para fazer o deploy da aplicação no Vercel, apenas faça o login na sua conta do Vercel e siga as instruções para conectar o repositório e configurar o deploy contínuo.
